How the week runs

Four workouts, run as a rolling cycle across five sessions a week — so the workouts don't line up with the same weekdays each week:

Week 1
Workout 1 → 2 → 3 → 4 → 1
Week 2
Workout 2 → 3 → 4 → 1 → 2

Each workout is 10 numbered sets. Do the moves within a set back-to-back, then take the stated recovery before the next set.

Hard sets
Shortness of breath, feeling slightly buzzed, heat waves on skin. Chase that feeling.
Steady sets
Medium intensity yet more sweat and harder to concentrate.
